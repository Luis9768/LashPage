# LashPage - Vittoria's Studio 🌸

Landing page mobile-first de alta conversão desenvolvida para **Vittoria's Studio**, especialista em extensão de cílios, lash mapping e realce do olhar em Santo André - SP.

## 🚀 Tecnologias

- **React 19** + **Vite 8**
- **Tailwind CSS v4**
- **Lucide React** (Ícones modernos)
- **Vercel / Netlify Ready**

## ✨ Funcionalidades

- **Intro Typewriter / Stream**: Introdução visual com efeito de digitação em tempo real (*"Está pronta para ficar maravilhosa?"*).
- **Bio & Hero Luxury Dark**: Banner personalizado de alta fidelidade e avatar integrado com links rápidos de agendamento e redes sociais.
- **Sub-telas Instantâneas**:
  - Catálogo interativo com filtros, descrição das técnicas (Fio a Fio, Volume Brasileiro, Volume Russo, etc.), duração e cuidados.
  - Página de localização com rotas (Google Maps & Waze), endereço com cópia rápida e mapa interativo de Santo André - SP.
- **Slider Antes & Depois Interativo**: Comparativo arrastável de procedimentos.
- **Integração de Agendamento**: Links diretos para a plataforma Maapp e WhatsApp.

## 📦 Como rodar localmente

```bash
# Instalar as dependências
npm install

# Iniciar servidor de desenvolvimento
npm run dev

# Gerar build de produção
npm run build
```
